Features

話したい瞬間を、もっとなめらかに。

録音もログも残さない、リアルタイムだけのコミュニケーション。Temportalは「今この瞬間」のためだけに作られています。

低遅延ボイスチャット

WebRTCをベースにしたリアルタイム通話。アカウント不要、ニックネームを入れてすぐ参加できる手軽さ。

ゲーム中の即席ボイスチャット

マッチングしたばかりの仲間とも、ルームコードをチャット欄に貼るだけで即合流。フレンド登録もアプリ間連携も要らず、対戦・協力プレイの作戦会議をその場で始められます。

使い捨てのルーム

ルームを抜ければ会話の痕跡は残りません。録音なし・履歴なし。「ワンタイムな空間」だから、本音で話せる。

画面共有

資料・ゲーム・思い出の写真。話しながらサッと共有して、視点をそろえる。リモートでも、隣にいる感覚を。

スマホからコントロール

PCで通話・画面共有しながら、手元のスマホでミュート、音量、退室をワンタップ操作。ゲーム中にAlt+Tabで画面を切り替える必要はもうありません。

サイドチャット

声を出しづらい場面でもテキストでサッと一言。ボイスとチャットを自然に切り替えられます。

グループ機能

友達同士でグループを作って、いつものメンバーで集まれる。仲間との「拠点」をすばやく開設。

クロスプラットフォーム

iOS / Android / Web / macOS / Windows / Linux に対応。手元のデバイスで、いつでもどこでも。

How it works

3ステップで、もう話してる。

ややこしい設定は要りません。アプリを開いて、ルーム名を入れて、共有するだけ。

ルームを作る

アプリを開いてルーム名とニックネームを入力。アカウント登録は不要です。

友達に共有

ルームコードや招待リンクを送るだけ。受け取った人はワンタップで参加できます。

退室で消える

会話を終えてルームを抜ければ、その空間ごと消滅。次の通話はまた新しい部屋で。
